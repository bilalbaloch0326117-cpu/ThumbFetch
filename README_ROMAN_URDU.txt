YOUTUBE THUMBNAIL DOWNLOADER — SETUP GUIDE (Roman Urdu)

FILES:
- index.html: Main website page
- style.css: Design / mobile layout
- script.js: YouTube URL parsing, image availability checks, preview and links
- about.html, privacy.html, contact.html: Basic information pages

LOCAL PC PAR TEST:
1. ZIP extract karein.
2. index.html par double-click karke browser mein khol dein.
3. YouTube video URL paste karein aur "Get Thumbnail" dabayein.
4. Agar browser ki local-file security issue de, to VS Code mein Live Server extension se folder open karein.

FREE ONLINE HOSTING (GitHub Pages):
1. github.com par free account banayein / sign in karein.
2. New repository banayein, misal ke taur par "thumbnail-downloader".
3. Repository mein in tamam files ko upload karein. README bhi upload kar sakte hain.
4. Repository Settings > Pages kholein.
5. "Deploy from a branch" choose karein, branch "main", folder "/ (root)" select karein, Save karein.
6. Kuch minutes baad GitHub Pages aapko website URL dega. Usi URL ko visitors ke saath share karein.
7. Agar website update karein to files dobara commit/upload kar dein.

IMPORTANT LIMITATIONS:
- Project HTML/CSS/JavaScript static website hai; paid API, database ya backend required nahi.
- Image availability check browser mein YouTube image URLs se hota hai. YouTube har video ke liye har size provide nahi karta.
- Browser cross-origin restrictions ki wajah se download button image ko new tab mein kholta hai. User image par right-click / long-press karke save kar sakta hai. Reliable direct-download proxy banane ke liye backend chahiye, lekin woh hosting/cost aur third-party terms ke mutabiq hoga.
- Kuch private, removed, age-restricted ya unavailable videos ka thumbnail load na ho.
- Google AdSense approval guaranteed nahi. Pehle original helpful content, genuine contact details, privacy disclosures, site navigation, policy compliance aur real traffic par focus karein. Sirf tool pages ki thin site ko approval milna guaranteed nahi.
- Free subdomain use karein; domain khareedna zaroori nahi.
- Thumbnails par copyright ho sakta hai. Download karne se reuse rights nahi milte.
- Website YouTube/Google ki official website nahi hai.

BEFORE ADS:
- Contact page mein apna real contact email add karein.
- Privacy policy ko apni actual setup ke mutabiq update karein.
- Misleading claims na karein aur copyright/brand policies follow karein.
- AdSense ke current rules aur eligibility apne account mein check karein.
